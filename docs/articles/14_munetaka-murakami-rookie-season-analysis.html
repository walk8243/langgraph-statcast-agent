-- [素材 1: 素材①: 月別・週別配球トレンドデータ]
-- 指示: 2026年シーズンの村上宗隆に対する全投球データ（Pitch-by-Pitch）を対象に、月別および週別の投球割合（4シーム、シンカー、スライダー、カーブ、チェンジアップ、スプリット等の球種別割合）を集計
WITH base AS (
    SELECT
        s.pitch_type,
        s.pitch_name,
        s.game_date,
        toMonth(s.game_date) AS pitch_month,
        toWeek(s.game_date) AS pitch_week
    FROM statcast.statcast_raw AS s
    JOIN statcast.players p FINAL ON toUInt64(s.batter) = p.player_id
    JOIN statcast.games g FINAL ON toUInt64(s.game_pk) = g.game_pk
    WHERE p.full_name LIKE '%Munetaka Murakami%'
      AND g.season = 2026
      AND g.game_type = 'R'
      AND s.pitch_name IS NOT NULL
)
SELECT
    pitch_month,
    pitch_week,
    pitch_name,
    count() AS pitch_count,
    round(count() * 100.0 / sum(count()) OVER (PARTITION BY pitch_month, pitch_week), 2) AS pitch_percentage
FROM base
GROUP BY pitch_month, pitch_week, pitch_name
ORDER BY pitch_month, pitch_week, pitch_count DESC

-- [素材 2: 素材②: 月別球種別・空振り適応データ]
-- 指示: 2026年シーズンの村上宗隆に対する月別の球種別スイング数、空振り数、Whiff%（空振り率）、およびコンタクト率を集計
SELECT
    toMonth(s.game_date) AS month,
    assumeNotNull(s.pitch_name) AS pitch_name,
    countIf(s.description IN ('swinging_strike', 'swinging_strike_blocked', 'foul', 'hit_into_play')) AS swings,
    countIf(s.description IN ('swinging_strike', 'swinging_strike_blocked')) AS whiffs,
    round(countIf(s.description IN ('swinging_strike', 'swinging_strike_blocked')) * 100.0 / nullIf(countIf(s.description IN ('swinging_strike', 'swinging_strike_blocked', 'foul', 'hit_into_play')), 0), 2) AS whiff_pct,
    round(countIf(s.description IN ('foul', 'hit_into_play')) * 100.0 / nullIf(countIf(s.description IN ('swinging_strike', 'swinging_strike_blocked', 'foul', 'hit_into_play')), 0), 2) AS contact_pct
FROM statcast.statcast_raw AS s
JOIN statcast.players p FINAL ON toUInt64(s.batter) = p.player_id
JOIN statcast.games g FINAL ON toUInt64(s.game_pk) = g.game_pk
WHERE p.full_name LIKE '%Munetaka Murakami%'
  AND g.season = 2026
  AND g.game_type = 'R'
  AND s.pitch_name IS NOT NULL
GROUP BY month, pitch_name
ORDER BY month ASC, swings DESC

-- [素材 3: 素材③: 月別打球品質データ]
-- 指示: 2026年シーズンの村上宗隆の月別打球データ（打席数、平均打球初速、HardHit%、Barrel%、xBA、xwOBA）を集計
WITH batting_box AS (
    SELECT
        bb.player_id AS player_id,
        toMonth(g.game_date) AS month_num,
        sum(bb.plate_appearances) AS pa
    FROM statcast.boxscore_batting bb FINAL
    JOIN statcast.players p FINAL ON bb.player_id = p.player_id
    JOIN statcast.games g FINAL ON bb.game_pk = g.game_pk
    WHERE p.full_name LIKE '%Munetaka Murakami%'
      AND g.season = 2026
      AND g.game_type = 'R'
    GROUP BY player_id, month_num
),
statcast_data AS (
    SELECT
        toUInt64(s.batter) AS player_id,
        toMonth(s.game_date) AS month_num,
        countIf(s.type = 'X' AND s.launch_speed IS NOT NULL) AS bbe_count,
        avg(if(s.type = 'X', s.launch_speed, NULL)) AS avg_launch_speed,
        countIf(s.type = 'X' AND s.launch_speed >= 95.0) AS hard_hit_count,
        countIf(s.type = 'X' AND s.launch_speed_angle = 6) AS barrel_count,
        avg(s.estimated_ba_using_speedangle) AS xba,
        avg(s.estimated_woba_using_speedangle) AS xwoba
    FROM statcast.statcast_raw s
    JOIN statcast.players p FINAL ON toUInt64(s.batter) = p.player_id
    JOIN statcast.games g FINAL ON toUInt64(s.game_pk) = g.game_pk
    WHERE p.full_name LIKE '%Munetaka Murakami%'
      AND g.season = 2026
      AND g.game_type = 'R'
    GROUP BY player_id, month_num
)
SELECT
    b.month_num AS month,
    sum(b.pa) AS plate_appearances,
    round(avg(sd.avg_launch_speed), 1) AS avg_launch_speed_mph,
    round(sum(sd.hard_hit_count) * 100.0 / nullIf(sum(sd.bbe_count), 0), 1) AS hard_hit_pct,
    round(sum(sd.barrel_count) * 100.0 / nullIf(sum(sd.bbe_count), 0), 1) AS barrel_pct,
    round(avg(sd.xba), 3) AS xba,
    round(avg(sd.xwoba), 3) AS xwoba
FROM batting_box b
LEFT JOIN statcast_data sd ON b.player_id = sd.player_id AND b.month_num = sd.month_num
GROUP BY b.month_num
ORDER BY b.month_num

村上宗隆の1年目を解剖する：相手投手陣の「警戒シフト」と月別配球変化の全貌

概要・エグゼクティブサマリー

日本が誇る圧倒的なスラッガー、村上宗隆がメジャーリーグベースボール（MLB）の舞台で迎えた1年目のシーズン。世界最高峰の投手陣は、日本の三冠王に対してどのようなアプローチを選んだのでしょうか。本記事では、最先端のStatcastデータを駆使し、村上に対して相手バッテリーがどのように配球を変化させ、それに対して彼がどう適応し、どのような打球品質を残してきたのかを時系列で徹底解剖します。

本記事の主要な発見・ハイライト：
- 配球の変遷: シーズン序盤（3〜4月）の速球・シンカー中心の配球から、4月以降はスライダーやチェンジアップ、スウィーパーなど多彩な変化球を交えた「厳戒態勢の配球」へと明確にシフト。
- コンタクトと空振りの攻防: 特にスライダーに対する空振り率（Whiff%）の高さが課題として浮き彫りになる一方、月ごとに変化球への対応を模索するタフな適応プロセスが見て取れる。
- 驚異的な打球品質: 相手の徹底マークと変化球攻勢にもかかわらず、平均打球初速やバレル率、期待打率（xBA）においてメジャーの一流打者と同等以上の圧倒的な数値・ハードヒット率を維持。

第1章：月別・週別に見る投球割合の変化（速球vs変化球のトレンド）

シーズンが開幕した3月、相手投手陣の村上に対するアプローチは、まず「動く速球」と「4シーム」でストライクゾーンを支配することから始まりました。3月の第12週時点では、4シーム（45.45%）とシンカー（27.27%）を合わせた直球系が全体の7割を超えていました。

しかし、その警戒感はすぐさま形を変えます。同月第13週、そして本格稼働した4月以降、カッター、チェンジアップ、スライダー、スウィーパーといった多彩な変化球の割合が急増。相手バッテリーは「村上にストレートを合わせさせない」ための配球へと完全にシフトしていきました。

第2章：配球の変化に対応するコンタクトと空振り（Whiff%）の推移

相手投手陣が変化球主体の配球へと舵を切る中、村上のバットがどう空を切ったのか、あるいはどうコンタクトを形成したのかを映し出すのが「Whiff%（空振り率）」と「Contact%（コンタクト率）」のデータです。

4月および5月の球種別データを見ると、村上の前に立ちはだかる「最大の壁」の正体が明確になります。

4月にはスライダーに対してWhiff%が 63.33%、チェンジアップに対して 57.14% と高い空振り率を記録しました。メジャー特有の鋭く曲がり沈む変化球に対し、序盤はタイミングや軌道へのアジャストに苦心した痕跡がうかがえます。

しかし特筆すべきは、5月に向けてその数字が着実に改善されている点です。スライダーに対するWhiff%は5月に 50.88% へと低下し、逆にコンタクト率が向上。またスウィーパーに対するコンタクト率も74.07%まで上昇しており、相手の配球の罠に対し、村上が打席内で着実にアジャストの糸口を掴んでいることがデータから証明されています。

第3章：打球品質から見えた「相手の攻めに対する成果」

この打球品質のデータ群は、村上宗隆という打者の「底知れぬ凄み」を物語っています。

  1. 爆発的な打球初速: 全体を通じて平均打球初速は93〜96 mph台をマークしており、特に4月には 96.3 mph という驚異的な数値を記録。これはメジャーリーグ全体でもトップクラスのハードヒットを生み出している証拠です。
  2. 高水準のバレル率: バットの芯で捉えた理想的な打球の割合を示す Barrel% は、シーズンを通して17.9%〜25.0%という圧倒的な高水準を維持。9月には 25.0% に達しており、捉えた時の破壊力は衰えるどころか増しています。
  3. 期待打率（xBA）と期待長打率（xwOBA）: 相手バッテリーがどれだけ変化球や厳しいコースを突こうとも、村上がコンタクトに成功した際の打球は極めて高い確率でヒット性の当たり（xBAは各月で.331〜.414の高水準）となっており、相手の配球の罠は「紙一重のところで村上の圧倒的なパワーに凌駕されている」と言っても過言ではありません。

まとめと今後の展望

2026年シーズン、メジャー1年目を戦う村上宗隆に対する相手投手陣の攻めは、当初の速球主体から、スライダー・チェンジアップ・スウィーパーをふんだんに交えた「変化球主体の高度な警戒シフト」へと移行しました。

一時的に空振り率 que 上昇し、厳しいデータが並んだ月もあったものの、村上はその卓越したバットコントロールとパワーでこれを粉砕しにかかりました。月ごとに変化球へのコンタクト率を高めつつ、打球初速やバレル率において常にトップクラスの品質を叩き出している事実は、彼が単なる「パワーヒッター」ではなく、メジャーの配球環境へ驚異的なスピードで適応しつつある「希代のヒットメーカー」であることを証明しています。

シーズン終盤、そして今後のキャリアに向けて、相手バッテリーがさらにどのような「新たな罠」を仕掛けてくるのか。それに対し、村上がいかにして進化を遂げ、さらに凄みを増した打球を飛ばしていくのか――MLBにおける村上宗隆の進化の物語から、今後も一瞬たりとも目が離せません。
