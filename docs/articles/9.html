-- [素材 1: 素材①: 総合オフェンス指標]
-- 指示: 2026年シーズンの鈴木誠也、村上宗隆、岡本和真のPA, AB, H, HR, RBI, R, BB%, K%, AVG, OBP, SLG, OPS, wOBA, wRC+ を集計するクエリ
SELECT
    p.full_name AS player_name,
    sum(bt.plate_appearances) AS pa,
    sum(bt.at_bats) AS ab,
    sum(bt.hits) AS h,
    sum(bt.home_runs) AS hr,
    sum(bt.rbi) AS rbi,
    sum(bt.runs) AS r,
    round(sum(bt.base_on_balls) / nullIf(sum(bt.plate_appearances), 0), 3) AS bb_pct,
    round(sum(bt.strike_outs) / nullIf(sum(bt.plate_appearances), 0), 3) AS k_pct,
    round(sum(bt.hits) / nullIf(sum(bt.at_bats), 0), 3) AS avg,
    round((sum(bt.hits) + sum(bt.base_on_balls) + sum(bt.hit_by_pitch)) / nullIf(sum(bt.at_bats) + sum(bt.base_on_balls) + sum(bt.hit_by_pitch) + sum(bt.sac_flies), 0), 3) AS obp,
    round(sum(bt.total_bases) / nullIf(sum(bt.at_bats), 0), 3) AS slg,
    round(obp + slg, 3) AS ops,
    CAST(NULL AS Nullable(Float32)) AS woba,
    CAST(NULL AS Nullable(Float32)) AS wrc_plus
FROM statcast.boxscore_teams AS bt
JOIN statcast.boxscore_positions AS bp ON bt.game_pk = bp.game_pk AND bt.team_id = bp.team_id
JOIN statcast.players AS p ON bp.player_id = p.player_id
JOIN statcast.games AS g ON toUInt64(bt.game_pk) = g.game_pk
WHERE g.season = 2026 
  AND g.game_type = 'R'
  AND (p.full_name LIKE '%Seiya Suzuki%' OR p.full_name LIKE '%Munetaka Murakami%' OR p.full_name LIKE '%Kazuma Okamoto%')
GROUP BY p.player_id, p.full_name
ORDER BY pa DESC

-- [素材 2: 素材②: 打球品質（Statcast）]
-- 指示: 2026年シーズンの鈴木誠也、村上宗隆、岡本和真の平均打球初速 (Average Exit Velocity)、最大打球初速 (Max Exit Velo)、バレル率 (Barrel%)、ハードヒット率 (HardHit%)、SweetSpot% を集計するクエリ
SELECT
    p.full_name AS player_name,
    round(avg(s.launch_speed), 2) AS avg_launch_speed_mph,
    round(max(s.launch_speed), 2) AS max_launch_speed_mph,
    round(countIf(s.launch_speed >= 95.0) * 100.0 / nullIf(count(s.launch_speed), 0), 2) AS hard_hit_pct,
    round(countIf(s.launch_angle BETWEEN 8 AND 32) * 100.0 / nullIf(count(s.launch_angle), 0), 2) AS sweet_spot_pct,
    round(countIf(
        s.launch_speed IS NOT NULL AND s.launch_angle IS NOT NULL AND
        (
            (s.launch_speed >= 98 AND s.launch_angle BETWEEN 26 AND 30) OR
            (s.launch_speed > 98 AND s.launch_angle BETWEEN (26 - (s.launch_speed - 98)) AND (30 + (s.launch_speed - 98))) OR
            (s.launch_speed >= 95 AND s.launch_angle BETWEEN (27 - (s.launch_speed - 95) * 0.5) AND (29 + (s.launch_speed - 95) * 0.5))
        )
    ) * 100.0 / nullIf(count(s.launch_speed), 0), 2) AS barrel_pct,
    count() AS total_batted_balls
FROM statcast.statcast_raw AS s
JOIN statcast.players AS p ON toUInt64(s.batter) = p.player_id
JOIN statcast.games AS g ON toUInt64(s.game_pk) = g.game_pk
WHERE (p.full_name ILIKE '%Seiya Suzuki%' OR p.full_name ILIKE '%Munetaka Murakami%' OR p.full_name ILIKE '%Kazuma Okamoto%')
  AND g.season = 2026
  AND g.game_type = 'R'
  AND s.launch_speed IS NOT NULL
GROUP BY player_name
ORDER BY avg_launch_speed_mph DESC

2026年のメジャーリーグベースボール（MLB）において、日本のファンを最も熱狂させているトピックの一つが、最高峰の舞台で躍動する「侍スラッガー3人衆」——鈴木誠也、村上宗隆、岡本和真のパフォーマンスです。

本記事では、伝統的な打率や本塁打数といった表面的なスタッツの枠を超え、Statcast（スタットキャスト）の高度なトラッキングデータから、3選手の「強みの源泉」と「メジャー適応のメカニズム」を多角的に解剖・比較します。

本記事の主要な発見・ハイライト

  • 圧倒的な打球初速の村上宗隆: 平均打球初速・最大初速・バレル率において、他の2人を大きく引き離す爆発的な「打球品質」を証明。

第3章：MLBの配球への適応度——速球・変化球・オフスピードへのアプローチ

MLB投手陣の代名詞である95 mphを超えるフォーシーム、魔球の異名を持つスイーパーやスプリットに対し、日本から渡ったスラッガーたちがどう対峙しているか。ここでは、洗練されたアプローチのプロセスを検証します。

配球適応のメカニズム

メジャー投手陣の配球における特徴は、「ゾーン高低・内外の激しい揺さぶり」と「球速差」にあります。
- 対速球（Fastball）への対応: 村上の持つ114.1 mphに代表される爆発的な最大初速は、MLBの豪速球を押し返すだけのスイングスピードが完備されている証拠です。
- 変化球・オフスピードへの対応: 鈴木誠也が長年培ってきたアプローチ眼は、スイーパーやフロントドアのフロントスライダーなど、ゾーン内外を見極める上で大きな武器となっています。岡本和真も、日本の広角打法をベースにしつつ、落ちる球（スプリット・チェンジアップ系）に対する見極めとコンタクト精度の向上がブレイクスルーの鍵となります。
