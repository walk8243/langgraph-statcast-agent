SELECT
    t.league_name,
    t.division_name,
    t.name AS team_name,
    t.abbreviation,
    count() AS games_played,
    countIf(b.runs > b.pitching_runs) AS wins,
    countIf(b.runs < b.pitching_runs) AS losses,
    round(countIf(b.runs > b.pitching_runs) / count(), 3) AS win_pct,
    sum(b.runs) AS runs_scored,
    sum(b.pitching_runs) AS runs_allowed,
    toInt32(sum(b.runs)) - toInt32(sum(b.pitching_runs)) AS run_diff,
    sum(b.home_runs) AS total_home_runs
FROM statcast.boxscore_teams AS b
INNER JOIN statcast.teams AS t ON b.team_id = t.team_id
WHERE b.game_pk IN (
    SELECT DISTINCT toUInt64(game_pk)
    FROM statcast.statcast_raw
    WHERE game_year = 2024
      AND game_type = 'R'
)
AND t.active = 1
AND t.division_name IS NOT NULL
GROUP BY
    t.league_name,
    t.division_name,
    t.name,
    t.abbreviation
ORDER BY
    t.league_name,
    t.division_name,
    win_pct DESC,
    run_diff DESC

詳細考察・データが示すポイント

1. 地区ごとの戦力バランスと「得失点差」の真実

2024シーズンをデータから俯瞰すると、各地区の構図が鮮明に浮かび上がります。
- アメリカン・リーグ東地区 (AL East): 例年通りの激戦区となり、ヤンキース（94勝）とオリオールズ（91勝）が上位を牽引。特にオリオールズは得失点差+172と、地区トップのヤンキース（+147）を上回る圧倒的な数字を残しており、投打の噛み合わせの良さが光りました。
- ナショナル・リーグ西地区 (NL West): ドジャースが圧倒的な勝率（.605、98勝）を記録し、得失点差も+141と地力を証明。それに続くパドレス（93勝）やダイヤモンドバックス（89勝）も非常に高い得点力を誇り、地区全体のハイレベルな殴り合いがデータ（ARIの総得点886など）に表れています。
- 歴史的低迷となったホワイトソックス: ア・リーグ中地区のシカゴ・ホワイトソックスは、勝率.253（41勝121敗）、得失点差-335という極端なシーズンとなりました。失点（841）が突出しており、投手陣の再構築が急務であるデータを示しています。

2. Statcast / 長打力トレンド：本塁打と得点効率の相関

現代MLBにおいて、打球初速（Exit Velocity）やバレル率（Barrel Rate）といったStatcast指標に直結するのが「本塁打数」です。
- 2024年シーズンで最も多くの本塁打を放ったのはボルチモア・オリオールズの257本であり、これにヤンキース（237本）、ドジャース（233本）、アスレチックス（215本）が続きます。
- オリオールズやヤンキースは、高い長打力をそのまま得点（BAL: 786点、NYY: 815点）に結びつけており、現代野球の「フライボールレボリューション」および強烈なパワーツールが勝利に直結していることが裏付けられます。
- 一方で、マイアミ・マーリンズ（121本）やシカゴ・ホワイトソックス（131本）など、本塁打数が低迷したチームは得点力不足に陥り、そのまま負け越しの大きな要因となりました。

3. 投打の総合力とポストシーズンへの示唆

勝率と得失点差の相関を見ると、運の要素（一時点での接戦勝率など）を排した「チームの本来の実力」が浮き彫りになります。
- ナショナル・リーグ東地区のフィラデルフィア・フィリーズは95勝（勝率.586）を挙げ、得失点差も+136と非常に安定した成績を残しました。投手陣の失点抑止力（642失点）と打線の爆発力が高い次元で融合しています。
- カンザスシティ・ロイヤルズ（86勝、得失点差+125）やデトロイト・タイガース（86勝、得失点差+69）のように、前年からの大きな躍進を遂げたチームは、いずれも投手陣の失点を効果的に抑え込むことに成功しています。

まとめと今後の展望

  • 強豪の条件: 年間を通じて得失点差が大きくプラスに転じているチーム（ドジャース、ヤンキース、フィリーズ、オリオールズなど）は、やはりポストシーズンでも主役を張るだけの高度なデータ的裏付け（高い打球初速、優れた失点抑制）を持っています。
  • 今後の注目ポイント: 各球団がこの膨大なStatcastデータやトラッキング情報をどのようにオフシーズンの補強や育成（プロスペクトの評価、投手の球種配分見直しなど）に活かすのかが、2025年シーズンに向けた最大の焦点となります。
